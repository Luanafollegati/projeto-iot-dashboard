Sobre o Projeto

Objetivo

Este projeto tem como objetivo monitorar temperatura, umidade e qualidade do ar utilizando um ESP32, sensores e comunicação MQTT.

Arquitetura

Os sensores enviam os dados para o ESP32. O ESP32 envia as informações para o Mosquitto utilizando MQTT. O Dashboard Web recebe os dados através de WebSockets.

Componentes

ESP32

DHT11

MQ-135

Limites de alerta

  • Temperatura: acima de 28 °C
  • Umidade: acima de 56%
  • Qualidade do ar: acima de 400

PROJETO IoT

Sobre o Projeto

O projeto consiste em uma estação de monitoramento IoT utilizando um ESP32 e sensores ambientais.

Os dados de temperatura, umidade e qualidade do ar são coletados pelos sensores e enviados através do protocolo MQTT para o servidor Mosquitto.

O Dashboard Web recebe essas informações em tempo real através de WebSockets e apresenta os dados de forma visual.

01

Hardware Utilizado

ESP32

Microcontrolador responsável pela leitura dos sensores e comunicação com o broker MQTT.

DHT11

Sensor utilizado para medir temperatura e umidade do ambiente.

MQ-135

Sensor utilizado para monitorar a qualidade do ar e presença de gases.
